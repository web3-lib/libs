@w3lib/ton-batch-call demo

TON 批量查询：通过 toncenter v3 索引器，多个地址、多个 Jetton 合成一个请求，自动限频排队。下面每次查询都会显示实际发出的请求数。

设置

未连接（只读查询不需要钱包）

没有 API Key 时 toncenter 限制每秒 1 次请求，库会自动排队（LP 查询要读多个池子，可能要十几秒）。API Key 在 Telegram 的 @tonapibot 免费申请。设置保存在本地浏览器。

余额getBalances：TON + Jetton，一次 accountStates + 一次 jetton/wallets

多个地址getMultiBalances / getWalletStates：TON + 指定 Jetton，钱包类型和 seqno

Jetton 信息getJettons：名称 / symbol / 精度 / 总量 / 是否诈骗代币

LP 仓位getLpPositions（子路径 /lp）：STON.fi v1 / v2、DeDust 的 LP Jetton，按份额算出撤出能拿到的数量

添加 / 移除流动性子路径 /liquidity：build* 只构建（报价 + 钱包要发的消息），连接钱包后可以直接发送

给一边的数量，另一边按池子的储备比例；token0 / token1 的顺序以报价结果为准。TON 那一边直接用 TON 支付，附带的 gas 多余的会退回。 移除时合约按当时的储备给，不检查下限。发送会在钱包里确认，交易真实上链，请先用小额试。钱包用 TON Connect（插件钱包或扫码）。

NFTgetNfts：地址持有的 NFT（含正在出售的），名称和图片取自索引器的元数据

价格子路径 /price：getTokenPrices 代币的美元价格、getPortfolio 地址的资产总值

默认先查 DefiLlama，没有收录的代币再从链上 STON.fi / DeDust 的池子算（取消“只用 DefiLlama”）；链上价格每个代币约 3~6 次请求，没有 API Key 时每秒 1 次，会慢很多。价格只用于展示，不要用来算交易的最小数量。

域名解析子路径 /names：TON DNS（.ton）和 Telegram 用户名（.t.me），名字 → 地址（链上 dnsresolve）、地址 → 名字（索引器 + 正查核对）

名字 → 地址每个名字 2 次 get 方法调用；地址 → 名字每 100 个地址 1 次索引器请求，核对再解析一遍名字。只有地址自己持有、并且指向自己的名字才算它的名字。

手续费估算子路径 /fees：toncenter emulateTrace 模拟整条交易链，不签名、不发送

转账用连接的钱包地址，没连接用顶部的地址（要已部署的 v4r2 / v5r1 钱包，余额不够付手续费时模拟不出来）。“上次兑换报价的消息”要先在“兑换”页报价，按报价时的账户估算。

兑换子路径 /swap：STON.fi v2 / v1、DeDust 里找最好的路线（直接或经过 TON / USD₮ 两跳），报价；连接钱包后可以发送

未连接（报价时用顶部的地址）

报价读多个池子，没有 API Key 时每秒 1 次请求，要二三十秒。最少收到 = 报价 × (1 − 滑点)，由 DEX 合约检查，不够时退款；附带的 TON 多余的退回。 发送默认只模拟整条交易链（不上链），取消勾选才会在钱包里确认并真实兑换，请先用小额试。只支持主网。

批量转账 子路径 /write：batchTransfer：多个收款人打包进同一笔交易

多个收款人打包进同一笔交易（v5r1 最多 255 条消息，v4r2 最多 4 条）。取消勾选“只模拟”后会弹出确认再发送，钱包里还要再确认。归集（多个钱包 → 一个地址）和通用批量调用要多个钱包的私钥，不放进浏览器 demo，用法见 README 的“批量写操作”。

Jetton 风险检查子路径 /risk：admin / 能否增发 / 诈骗标记 / 钱包代码，可选模拟买入卖出（貔貅盘、转账税）

模拟用 /swap 的路线、找一个持有人的钱包模拟两笔（不发送、不签名），每个代币多约 30 次请求。只能发现模拟时的行为，针对特定地址、时间、数量的限制不一定能发现。索引器的诈骗标记很少，标记为空不等于安全。

模拟子路径 /simulate：模拟整条交易链（不签名、不发送）：余额变化、手续费、可读的错误、消息解码、警告

发送的钱包同“手续费估算”（连接的钱包，或顶部地址栏里已部署的 v4r2 / v5r1 钱包）。余额变化只列钱包 / 普通地址，不列 DEX 和 Jetton 钱包。

交易历史子路径 /history：toncenter 已分类的动作（兑换 / 转账 / 流动性 / 增发 / 失败），出错退回 transactions

查顶部的地址，每页 10 条（同一条交易链的动作合成一条）。
