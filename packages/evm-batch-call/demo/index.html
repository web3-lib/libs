@w3lib/evm-batch-call demo

EVM / Tron 批量查询：所有合约读取经 Multicall3 合并，下面每次查询都会显示实际发出的节点请求数。

设置

内置公共节点限频较严，偶尔失败时库会自动换节点；频繁使用请填自己的节点。设置保存在本地浏览器。

余额 getBalances：主币 + 代币，一次 multicall

代币信息 getTokens：name / symbol / decimals / totalSupply

资产列表 getOwnerTokens（子路径 /owner）：从公开代币列表发现代币，链上核对余额

只能发现公开代币列表里的代币，结果不保证完整；要查几千个代币的余额，可能需要几秒。Tron 没有默认的代币来源（需要在代码里传 source）。

LP 仓位 getLpPositions（子路径 /lp）：V2 LP 代币、V3 / V4 仓位 NFT

V2 用常用计价币之间的组合找池子，只能尽量查；质押到农场（MasterChef）的仓位 NFT 不在用户名下，查不到。

添加 / 移除流动性 子路径 /liquidity：build* 只构建（报价 + 要发送的交易），连接钱包后可以直接发送

未连接（只构建时用上面“地址”栏的地址）

新建仓位不填价格区间时是全区间；报价结果里有池子当前的价格，可以据此再填区间。发送会在钱包里逐笔确认（授权在前），交易真实上链，请先用小额试。 已有仓位的追加 / 移除要由仓位的所有者发送。

NFT 子路径 /nft：集合信息、持有人、元数据地址

价格 / 资产总值 子路径 /price：getTokenPrices（DefiLlama，没收录的从链上池子算）、getPortfolio（余额 × 价格）

EVM 不能只靠节点列出持仓，资产总值只计入上面列出的代币（想自动发现用“资产列表”）。

授权 子路径 /approvals：批量读 ERC20 / Permit2 / NFT 授权，批量撤销

先查询，勾选要撤销的授权（默认勾选无限授权的）

撤销要由授权的所有者发送：钱包地址要和查询时的地址一致；每笔撤销在钱包里单独确认，交易真实上链。钱包用上面“添加 / 移除流动性”的“连接钱包”。

域名 子路径 /names：ENS（Ethereum）、SPACE ID（BNB Chain）、Basenames（Base）正向 + 反向解析

反向解析只返回正查也回到同一个地址的名字。只有 Ethereum、BNB Chain、Base 有内置的域名服务。

手续费 子路径 /fees：EIP-1559 三档建议；一笔交易的手续费（含 L1 数据费；Tron 算要烧的 TRX）

估算会在节点上执行一遍交易，会 revert 的交易（余额不够等）估算不出来；只估算，不发送。

兑换 子路径 /swap：在内置 V2 / V3 池子里找最好的路线（直接或两跳），报价后可以用钱包发送

带转账税的代币要填税率（V2 报价不含税，不填会因 INSUFFICIENT_OUTPUT_AMOUNT 回滚；V3 不支持带税的代币），税率可以用下面“代币风险”查。 报价和“最少收到”按不含税算。发送用“添加 / 移除流动性”里连接的钱包（授权在前，逐笔确认），交易真实上链，请先用小额试。

代币风险 子路径 /risk：模拟买入 / 转账 / 卖出，算买卖税、判断貔貅盘，看是否可升级代理、owner 是否放弃

只在这条链内置的 V2 协议的“代币 / 包装主币”池子里用 eth_call 模拟，不发交易；没有这样的池子（或只在 V3 有流动性）时测不出税。结果是模拟，不能保证以后不变。
