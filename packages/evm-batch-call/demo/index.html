@w3lib/evm-batch-call demo

EVM / Tron 批量查询：所有合约读取经 Multicall3 合并，下面每次查询都会显示实际发出的节点请求数。

设置

内置公共节点限频较严，偶尔失败时库会自动换节点；频繁使用请填自己的节点。设置保存在本地浏览器。

余额 getBalances：主币 + 代币，一次 multicall

代币信息 getTokens：name / symbol / decimals / totalSupply

资产列表 getOwnerTokens（子路径 /owner）：从公开代币列表发现代币，链上核对余额

只能发现公开代币列表里的代币，结果不保证完整；要查几千个代币的余额，可能需要几秒。Tron 没有默认的代币来源（需要在代码里传 source）。

LP 仓位 getLpPositions（子路径 /lp）：V2 LP 代币、V3 / V4 仓位 NFT

V2 用常用计价币之间的组合找池子，只能尽量查；质押到农场（MasterChef）的仓位 NFT 不在用户名下，查不到。

添加 / 移除流动性 子路径 /liquidity：build* 只构建（报价 + 要发送的交易），连接钱包后可以直接发送

未连接（只构建时用上面“地址”栏的地址）

新建仓位不填价格区间时是全区间；报价结果里有池子当前的价格，可以据此再填区间。发送会在钱包里逐笔确认（授权在前），交易真实上链，请先用小额试。 已有仓位的追加 / 移除要由仓位的所有者发送。

NFT 子路径 /nft：集合信息、持有人、元数据地址
