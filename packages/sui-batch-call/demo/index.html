@w3lib/sui-batch-call demo

Sui 批量查询：浏览器里直接用 gRPC-web 访问全节点（Sui 已停用 JSON-RPC），对象按批读取、多个查询并发发出。下面每次查询都会显示实际发出的 gRPC 调用。

设置

内置的公共全节点限频严，频繁查询时请填自己的节点或服务商的 gRPC-web 地址。设置保存在本地浏览器。

余额 getBalances：留空时 ListBalances 返回全部代币；指定代币时每个一次 GetBalance，并发发出

代币信息 getCoins：名称 / symbol / 精度 / 总供应量（GetCoinInfo）

LP 仓位 getLpPositions（子路径 /lp）：Cetus、Bluefin、Momentum、Turbos、Magma、FlowX、Kriya 的 CLMM 仓位和 Cetus DLMM 仓位（数量、手续费、奖励由合约在只读调用里算出），DipCoin、FlowX V2、Kriya 的 AMM LP，Aftermath 的多币池 LP

添加 / 移除流动性 子路径 /liquidity：build* 只构建（报价 + 交易内容），连接钱包后可以直接发送

未连接（只构建时用上面“地址”栏的地址）

给一边的数量，另一边按当前价格（集中流动性）或储备比例（AMM）；token0 / token1 的顺序以报价结果为准。DLMM 要填价格区间，两边各自给。 多币池给其中一种币的数量，其余的币按池子的比例。发送会在钱包里确认，交易真实上链，请先用小额试。

价格 / 资产总值 子路径 /price：tokenPrices（DefiLlama，没收录的从 Cetus、Turbos、FlowX 的池子算）、portfolio（持有的全部代币 × 价格，可选加上 LP 仓位）

历史价格只有 DefiLlama 能给（不填日期为当前价格，链上价格源只给当前的）。资产总值要读每个代币的信息、给没收录的代币找池子，持币很多的地址会发出较多请求； “只列出价值”只影响列出的代币，不影响合计。

域名 子路径 /names：SuiNS，名字 → 地址（resolveNames），地址 → 默认名字（lookupAddresses，正查核对过）

SuiNS 只部署在主网和测试网（节点填测试网地址时用测试网的部署）。过期的名字没有地址；地址的反查记录要指回这个地址才算默认名字。

手续费 子路径 /fees：estimateFees（当前参考 gas 价格），estimateCost（一笔交易模拟执行，不发送）

SUI

估算一笔“从 gas 币拆出这些 SUI 转给接收地址”的交易，发送者是上面“地址”栏的地址，要持有 SUI（只模拟，不需要私钥，不会发送）。 Sui 的 gas 价格每个 epoch 才定一次，没有分档；gas 上限是发送时给的上限，实际花费是净花费。

兑换 子路径 /swap：在 12 个协议里找最好的路线（直接或经过 SUI / USDC 两跳），每条路线用只读调用报价；连接钱包后可以发送

未连接（只报价时用上面“地址”栏的地址）

只支持卖出固定数量；卖出 SUI 以外的代币时，发送者要持有足够的数量（否则报价报 Insufficient balance）。最少收到的数量在交易里检查，超出滑点时交易失败。 发送会在钱包里确认，交易真实上链，请先用小额试。

代币风险 子路径 /risk：监管币（能否冻结地址、全局暂停）、增发权限（TreasuryCap 在谁手里）、元数据能否修改，可选模拟买入再卖出

模拟买入再卖出在只读调用里执行（不发送交易、不需要持有 SUI），会多发出每条候选路线一次调用，默认不开。 Sui 上的“貔貅”主要靠监管币冻结买家地址，模拟看不出来，要结合“监管币”一列看。

NFTgetNfts：地址拥有的 NFT，名称、图片取自节点渲染的 Display

对象 getObjects：按 ID 读对象（BatchGetObjects，每次 50 个），不存在的为 null
