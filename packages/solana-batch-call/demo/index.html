@w3lib/solana-batch-call demo

Solana 批量查询：账户用 getMultipleAccounts 一次读一批，同一时刻的调用合并成一个 JSON-RPC 批量请求。下面每次查询都会显示实际发出的节点请求数。

设置

未连接（只读查询不需要钱包）

内置公共节点（publicnode）限频严，也不支持 getTokenAccountsByOwner 等索引方法：余额、代币信息、NFT 详情可以直接查， 资产列表、持有的 NFT、NFT 持有人需要填自己的节点（Helius 等的免费额度即可）。官方节点 api.mainnet-beta 拒绝浏览器里的请求。设置保存在本地浏览器。

余额getBalances：SOL + SPL Token / Token-2022，本地推导 ATA 地址，一次 getMultipleAccounts

代币信息getTokens：name / symbol / decimals / supply / 所属程序 / 转账手续费

资产列表getOwnerTokens：地址持有的全部代币（需要自己的节点）

LP 仓位getLpPositions（子路径 /lp）：Raydium CLMM / Orca Whirlpool 仓位 NFT，Raydium AMM v4 / CPMM 的 LP 代币

添加 / 移除流动性子路径 /liquidity：build* 只构建（报价 + 要执行的指令），连接钱包后可以直接发送

集中流动性不填价格区间时是全区间（AMM 没有区间，给一边的数量，另一边按储备比例）；报价结果里有池子当前的价格。 发送会在钱包里确认，交易真实上链，请先用小额试。新建仓位时会生成仓位 NFT 的临时密钥，由本页面一起签名。

NFTgetNfts / getNftOwners / getOwnerNfts：Metaplex 元数据、持有人

价格子路径 /price：getTokenPrices（DefiLlama，没有收录的从链上 Raydium / Orca 池子算）、getPortfolio（资产总值）

授权管理子路径 /approvals：代币账户的授权（delegate）、可以关闭回收租金的空账户，批量撤销 / 关闭

撤销 / 关闭只处理上面最近一次查询出的账户，钱包要是这些账户的 owner（在顶部连接钱包）。关闭账户会退回租金并去掉授权，不可恢复；发送在钱包里确认，交易真实上链。

账户回收子路径 /reclaim：空代币账户、垃圾币（销毁后关闭）、Wrapped SOL、已清空的 Orca / Raydium CLMM 仓位，关闭后退回租金（SOL）

只列出能回收的账户；垃圾币的默认勾选很保守（有价格且价值高的、NFT、仓位 NFT 不会出现），没有价格也没有垃圾特征的只列出、不勾选，请自己确认。模拟用 /simulate，不签名；回收会在钱包里确认，垃圾币会被销毁、账户关闭，不可恢复。

批量领取子路径 /claim：Orca Whirlpool、Raydium CLMM 仓位的未领取手续费和挖矿奖励，预览、模拟、批量领取

预览只读取、不发交易；扫描仓位用“LP 仓位”里的 mint（留空时列出地址的全部代币账户，需要自己的节点）。模拟和领取处理最近一次预览出的全部仓位，钱包要是仓位的 owner。

域名解析子路径 /names：SNS（Bonfida，.sns）名字 → 地址、地址 → 主域名

默认不解析 .sol：它正在迁到另一个注册服务（SRS），SNS 官方 SDK 从 2026-10-15 前后起不再解析，同一个 .sol 名字以后可能属于别人， 这时结果里服务为空、地址为空。勾选“也解析 .sol”才会当作同名的 .sns 解析，转账前请自己确认。

手续费子路径 /fees：三档优先费建议，一笔交易的花费（基础费 + 优先费 + 新建账户的押金）

估算转账：地址是“地址”栏的（付手续费，要有 SOL），转给自己 0.000001 SOL，只在节点上模拟，不发送。

兑换子路径 /swap：Raydium CLMM / Orca Whirlpool / Raydium CPMM / AMM v4 的池子里找最好的路线，本地报价，连接钱包后可以发送

报价用连接的钱包地址，没连接时用“地址”栏的。发送会在钱包里确认，交易真实上链，请先用小额试；最少收到按滑点计算，价格影响大时不要发。

批量转账 子路径 /write：batchTransfer：多个收款人打包进同一笔交易（超过 1232 字节自动分笔）

一笔交易装不下时自动分笔；代币收款人没有关联代币账户时自动创建（由你出租金）。取消勾选“只模拟”后会弹出确认再发送，钱包里还要再确认。归集（多个钱包 → 一个地址）和通用批量调用要多个钱包的私钥，不放进浏览器 demo，用法见 README 的“批量写操作”。

代币风险子路径 /risk：增发 / 冻结权限，Token-2022 里影响持有人的扩展；可选模拟买入再卖出判断能不能卖

模拟买卖用连接的钱包地址（没连接时用“地址”栏的），需要有足够的 SOL；只在节点上模拟，不发送、不扣费。

交易模拟子路径 /simulate：余额变化、授权变化、指令说明、程序错误、警告；不签名、不发送

以连接的钱包地址（没连接时用“地址”栏的）为准算余额变化；交易里的手续费支付者不是它时，余额变化按它自己的账户算。

交易历史子路径 /history：兑换、转账、授权、流动性、铸造、失败；游标是最后一条签名
