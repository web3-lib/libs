@w3lib/solana-batch-call demo

Solana 批量查询：账户用 getMultipleAccounts 一次读一批，同一时刻的调用合并成一个 JSON-RPC 批量请求。下面每次查询都会显示实际发出的节点请求数。

设置

内置公共节点（publicnode）限频严，也不支持 getTokenAccountsByOwner 等索引方法：余额、代币信息、NFT 详情可以直接查， 资产列表、持有的 NFT、NFT 持有人需要填自己的节点（Helius 等的免费额度即可）。官方节点 api.mainnet-beta 拒绝浏览器里的请求。设置保存在本地浏览器。

余额 getBalances：SOL + SPL Token / Token-2022，本地推导 ATA 地址，一次 getMultipleAccounts

代币信息 getTokens：name / symbol / decimals / supply / 所属程序 / 转账手续费

资产列表 getOwnerTokens：地址持有的全部代币（需要自己的节点）

LP 仓位 getLpPositions（子路径 /lp）：Raydium CLMM / Orca Whirlpool 仓位 NFT，Raydium AMM v4 / CPMM 的 LP 代币

添加 / 移除流动性 子路径 /liquidity：build* 只构建（报价 + 要执行的指令），连接钱包后可以直接发送

未连接（只构建时用上面“地址”栏的地址）

集中流动性不填价格区间时是全区间（AMM 没有区间，给一边的数量，另一边按储备比例）；报价结果里有池子当前的价格。 发送会在钱包里确认，交易真实上链，请先用小额试。新建仓位时会生成仓位 NFT 的临时密钥，由本页面一起签名。

NFT getNfts / getNftOwners / getOwnerNfts：Metaplex 元数据、持有人

价格 子路径 /price：getTokenPrices（DefiLlama，没有收录的从链上 Raydium / Orca 池子算）、getPortfolio（资产总值）

授权管理 子路径 /approvals：代币账户的授权（delegate）、可以关闭回收租金的空账户，批量撤销 / 关闭

撤销 / 关闭只处理上面最近一次查询出的账户，钱包要是这些账户的 owner（在“添加 / 移除流动性”里连接钱包）。关闭账户会退回租金并去掉授权，不可恢复；发送在钱包里确认，交易真实上链。

域名解析 子路径 /names：SNS（Bonfida，.sns）名字 → 地址、地址 → 主域名

默认不解析 .sol：它正在迁到另一个注册服务（SRS），SNS 官方 SDK 从 2026-10-15 前后起不再解析，同一个 .sol 名字以后可能属于别人， 这时结果里服务为空、地址为空。勾选“也解析 .sol”才会当作同名的 .sns 解析，转账前请自己确认。

手续费 子路径 /fees：三档优先费建议，一笔交易的花费（基础费 + 优先费 + 新建账户的押金）

估算转账：地址是“地址”栏的（付手续费，要有 SOL），转给自己 0.000001 SOL，只在节点上模拟，不发送。

兑换 子路径 /swap：Raydium CLMM / Orca Whirlpool / Raydium CPMM / AMM v4 的池子里找最好的路线，本地报价，连接钱包后可以发送

报价用连接的钱包地址，没连接时用“地址”栏的。发送会在钱包里确认，交易真实上链，请先用小额试；最少收到按滑点计算，价格影响大时不要发。

代币风险 子路径 /risk：增发 / 冻结权限，Token-2022 里影响持有人的扩展；可选模拟买入再卖出判断能不能卖

模拟买卖用连接的钱包地址（没连接时用“地址”栏的），需要有足够的 SOL；只在节点上模拟，不发送、不扣费。
